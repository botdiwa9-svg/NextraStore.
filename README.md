# Nextra Store
โปรเจกต์ Android ใหม่สำหรับระบบคีย์ของ Nextra Store

ค่า Admin เริ่มต้นสำหรับเดโม:
- Username: admin
- Password: nextra123

ฟังก์ชัน:
- Login ด้วยคีย์
- Admin Panel
- สร้างคีย์
- ต่อ/ชดเชยคีย์ +7 วัน
- ยกเลิกคีย์
- ใช้โลโก้ที่ผู้ใช้ส่งมา

หมายเหตุ: นี่เป็นต้นแบบแบบ local/offline สำหรับการพัฒนา ระบบ production ควรย้ายการตรวจคีย์และ Admin ไป server พร้อม authentication ที่ปลอดภัย
